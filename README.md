# HUNT2BUILD — CSE Club · ESI

## Live website

Visit the HUNT2BUILD experience online: [qr-sable-phi.vercel.app](https://qr-sable-phi.vercel.app/)

## The event

HUNT2BUILD is a One Piece-themed hackathon organised by the CSE Club at ESI.

Participants become crews, search the ESI campus for hidden QR-code treasures, unlock a challenge, and build a working solution together. The event turns the hackathon into an adventure: **find it, unlock it, build it**.

## What happens

1. **Find it** — Explore the campus map and hunt for one of nine hidden QR codes.
2. **Unlock it** — Scan an available code to reveal your crew’s challenge.
3. **Build it** — Analyse the problem, create a prototype, and prepare your pitch.
4. **Pitch it** — Present the final solution to the jury and compete for the crown.

The website also presents the event agenda, challenge tracks, registration call to action, event objectives, and official CSE Club social channels.

## About the website

The website is the visual starting point for the HUNT2BUILD adventure. It is designed to make visitors feel the atmosphere of the event before it begins:

- One Piece-inspired treasure-hunt visuals.
- Illustrated map, compass, rings, flags, and QR-code artwork.
- Bold sand, mint, copper, and dark colors.
- Clear sections explaining the event journey.
- Interactive QR treasure board with mobile swipe support.
- Responsive schedule that works on desktop and phone.
- Smooth reveal transitions while scrolling.
- Mobile navigation and accessible labels.
- Official links to CSE Club social media.

## Event atmosphere

HUNT2BUILD is about exploration, teamwork, creativity, and building under pressure. Every crew follows its own route, discovers its challenge, and works toward one goal: turning a hidden problem into a real solution.

> Scan the code. Solve the problem. Find the treasure.
